# COMPAH Huila Prototipo v2.1.12 — AgroEco Style

Versión construida sobre la base v2.1.12, con rediseño premium inspirado en la lógica de presentación web de AgroEco.Red y adaptado a Compra Local Huila / COMPAH.

## Enfoque

COMPAH deja de sentirse como un tablero administrativo y pasa a presentarse como una plataforma territorial viva:

- Inicio inmersivo con imagen rural y narrativa institucional.
- Navegación superior horizontal tipo plataforma web.
- Mercado institucional local con buscador protagonista, chips y tarjetas visuales.
- Mapa de actores con buscador grande, filtros tipo píldora, leyenda y lectura territorial.
- Red de actores: productores, ACFC, operadores, entidades y supervisores.
- Servicios para registro, asistencia técnica, logística, trazabilidad y reportes.
- Trazabilidad de compra local bajo Ley 2046.
- Comunidad con historias, biblioteca, guías y agenda territorial.
- Dashboard / reportes como módulo gerencial, no como pantalla principal.
